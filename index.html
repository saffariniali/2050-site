Why the patterns are the same across implementations

The visualisation above runs the same JavaScript stencil regardless of which implementation you click — only the speed changes. That mirrors the project's main verification claim: all five real implementations produce the same field to within machine epsilon, so the only thing that differs across paradigms is throughput.
